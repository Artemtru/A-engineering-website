# Сайт ООО «А-Инжиниринг»

Одностраничный сайт-визитка: монтаж инженерных систем (ОВ, ВК, ЭОМ, СС, ИТП, АУПТ/АУПВ).
Чистый HTML + CSS + JS, без сборщиков.

## Структура
- `index.html` — главная (правится руками)
- `uslugi/`, `obekty/`, `o-kompanii/`, `politika-konfidencialnosti/` — внутренние страницы,
  **генерируются** скриптом `tools/build.py` (тексты правим в нём, затем `python3 tools/build.py`)
- `css/style.css` — общие стили всех страниц
- `sitemap.xml` — тоже создаётся скриптом
- `img/` — фото объектов (сжаты под веб), `img/og.jpg` — превью для мессенджеров
- `favicon.svg`, `favicon.png` — иконка вкладки
- `robots.txt`, `sitemap.xml` — для поисковиков
- `.nojekyll` — чтобы GitHub Pages отдавал файлы как есть

## Публикация
Сайт живёт на хостинге reg.ru (a-engineering.pro). Загружать в `public_html` всё, кроме `.git`, `tools`, `supabase`, `README.md`.
Обязательно загрузить скрытый файл `.htaccess` (https, без www, без дублей `index.html`, страница 404) и `send-lead.php` (форма заявки).

## Отладка на GitHub Pages
Settings → Pages → Source: Deploy from a branch → `main` / `(root)` → Save.
Адрес: `https://<логин>.github.io/<репозиторий>/`.
Внимание: копия на GitHub Pages открыта для поисковиков — после проверки отключите Pages, чтобы не было дубля сайта.

## Цели Метрики (уже размечены в коде)
- `phone_click` — клик по телефону
- `email_click` — клик по почте
- `form_submit` — отправка заявки
Создать их в Метрике: Цели → Добавить цель → «JavaScript-событие» с этими идентификаторами.

## Форма заявки
Форма отправляет заявку на `/send-lead.php` — обработчик на хостинге reg.ru.
Он ничего не хранит: сразу пересылает заявку письмом через почту хостинга. Данные не уходят за рубеж (152-ФЗ).

Настройки в начале `send-lead.php`:
- `MAIL_TO` — куда приходят заявки (сейчас `info@engineeringsys.ru`; после создания ящика на reg.ru поменять на `info@a-engineering.pro`);
- `MAIL_FROM` — от чьего имени уходит письмо (адрес на домене сайта).

Защита: только POST с a-engineering.pro, скрытое поле-ловушка для ботов, проверка и обрезка полей,
не чаще одной заявки в 30 секунд с одного IP.

После загрузки на хостинг — отправить тестовую заявку и проверить, что письмо пришло (и не попало в спам).

Папка `supabase/` — прежний вариант формы (Supabase Edge Function), больше не используется: бесплатный проект засыпает
после 7 дней без запросов.
