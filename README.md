# Сайт ООО «А-Инжиниринг»

Одностраничный сайт-визитка: монтаж инженерных систем (ОВ, ВК, ЭОМ, СС, ИТП, АУПТ/АУПВ).
Чистый HTML + CSS + JS, без сборщиков.

## Структура
- `index.html` — сайт
- `img/` — фото объектов (сжаты под веб), `img/og.jpg` — превью для мессенджеров
- `favicon.svg`, `favicon.png` — иконка вкладки
- `robots.txt`, `sitemap.xml` — для поисковиков
- `.nojekyll` — чтобы GitHub Pages отдавал файлы как есть

## Отладка на GitHub Pages
Settings → Pages → Source: Deploy from a branch → `main` / `(root)` → Save.
Адрес: `https://<логин>.github.io/<репозиторий>/`.
Пока сайт на GitHub, в `index.html` стоит `<meta name="robots" content="noindex, nofollow">` — копия не попадёт в поиск.

## Чек-лист перед переносом на reg.ru
1. Удалить строку `<meta name="robots" content="noindex, nofollow">` из `index.html`.
2. Вписать номер счётчика Метрики: `var YM_ID = 0;` → `var YM_ID = 12345678;`.
3. Вставить meta-тег подтверждения Яндекс.Вебмастера (место отмечено комментарием).
4. Проверить домен в `canonical`, `og:url`, `robots.txt`, `sitemap.xml` (сейчас `https://engineeringsys.ru/`).
5. Форма заявки уже подключена к Supabase (см. ниже) — проверить, что письма приходят с боевого домена.
6. Добавить страницу политики обработки персональных данных (152-ФЗ) и ссылку на неё у формы.
7. Загрузить все файлы в `public_html` на хостинге reg.ru, включить SSL (https).

## Цели Метрики (уже размечены в коде)
- `phone_click` — клик по телефону
- `email_click` — клик по почте
- `form_submit` — отправка заявки
Создать их в Метрике: Цели → Добавить цель → «JavaScript-событие» с этими идентификаторами.

## Форма заявки (Supabase)
Проект Supabase: `a-engineering-site` (`wklvjyyichcjiphozzrn`, eu-central-1).
Функция: `send-lead` → `https://wklvjyyichcjiphozzrn.supabase.co/functions/v1/send-lead`
Исходник: `supabase/functions/send-lead/index.ts`.

Функция **ничего не хранит**: принимает заявку и сразу пересылает письмом на почту (Яндекс 360).
Персональные данные не записываются в базу за рубежом.

### Настройка (один раз)
1. Яндекс ID → Безопасность → Пароли приложений → «Почта» → создать пароль.
   В настройках почты Яндекс 360 должен быть разрешён доступ по протоколам (IMAP/SMTP с паролями приложений).
2. supabase.com → проект → Edge Functions → Secrets (Manage secrets) → добавить:
   - `SMTP_USER` = `info@engineeringsys.ru`
   - `SMTP_PASS` = пароль приложения из шага 1
   - (необязательно) `MAIL_TO` — если заявки слать на другой адрес
3. Отправить тестовую заявку с сайта на GitHub Pages.

### Защита
- принимаются запросы только с engineeringsys.ru, *.github.io и localhost (доп. адреса — секрет `ALLOWED_ORIGINS`);
- скрытое поле-ловушка для ботов;
- проверка и обрезка длины полей.

### Важно
Бесплатный проект Supabase «засыпает» после 7 дней без запросов к базе. Функциям это не мешает,
но если в панели появится пометка Paused — нажать Restore.
