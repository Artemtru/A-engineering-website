Политика обработки персональных данных

ООО «А-ИНЖИНИРИНГ», сайт a-engineering.pro

1. Общие положения

Настоящая политика определяет порядок обработки персональных данных пользователей сайта a-engineering.pro (далее — Сайт) в соответствии с Федеральным законом от 27.07.2006 № 152-ФЗ «О персональных данных».

Оператор персональных данных — ООО «А-ИНЖИНИРИНГ», ИНН 9729423201, ОГРН 1267700271200, адрес: 119530, г. Москва, Очаковское шоссе, д. 34, помещ. 23/4. Контакт для обращений по вопросам персональных данных: info@a-engineering.pro.

2. Какие данные мы обрабатываем

Имя, номер телефона и текст сообщения, которые пользователь сам указывает в форме заявки. Также сервис Яндекс.Метрика собирает обезличенные данные о посещении Сайта (cookie, IP-адрес, сведения о браузере и действиях на Сайте).

3. Цели обработки

Связаться с пользователем по его заявке, подготовить расчёт стоимости работ и коммерческое предложение; анализировать посещаемость Сайта для его улучшения.

4. Правовое основание

Согласие пользователя, которое он даёт, отправляя форму заявки на Сайте.

5. Порядок обработки

Данные из формы заявки передаются на электронную почту Оператора и в базе данных Сайта не сохраняются. Для пересылки заявки используется облачный сервис обработки запросов. Оператор не передаёт персональные данные третьим лицам, за исключением случаев, предусмотренных законодательством РФ.

Данные хранятся не дольше, чем этого требуют цели обработки, после чего удаляются.

6. Права пользователя

Пользователь может запросить сведения об обработке своих данных, потребовать их уточнения или удаления, а также отозвать согласие, направив запрос на info@a-engineering.pro. Оператор ответит в сроки, установленные законом.

7. Изменение политики

Оператор вправе изменять настоящую политику. Актуальная версия всегда размещена на этой странице.
